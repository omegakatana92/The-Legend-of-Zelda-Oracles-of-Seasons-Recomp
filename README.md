The Legend of Zelda: Oracle of Seasons — Recomp

A modern recompilation project for The Legend of Zelda: Oracle of Seasons, originally released for the Nintendo Game Boy Color.

ROM Required

This project does not include the original game ROM or copyrighted Nintendo assets.

You must provide your own legally obtained ROM.

Features
Game Boy Color recompilation
Requires the user's own ROM
No copyrighted ROM files included
No original Nintendo assets included
Fullscreen support
Alt + Enter toggles fullscreen

Keyboard controls
Community contribution support

Building From Source
git clone https://github.com/YOUR-USERNAME/Zelda-Oracle-of-Seasons-Recomp.git
cd Zelda-Oracle-of-Seasons-Recomp
cmake -S . -B build
cmake --build build --config Release

The original ROM is not included.
